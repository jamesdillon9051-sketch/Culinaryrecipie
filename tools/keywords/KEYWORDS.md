# Weekly Delight: keyword list

Built from the site's own data (5515 recipes). These are search phrases taken from each page's keyword field, grouped for planning. They are **not** search-volume figures: this repository has no access to a keyword-volume source. Check volumes in Google Search Console (Performance > Queries), Google Keyword Planner or Google Trends before prioritising.

Every recipe's primary and supporting phrases are in `tools/keywords/KEYWORDS.csv` (one row per recipe, with its page URL).

## 4. Modifier patterns that fit the catalogue

- easy, simple, beginner, quick, 30 minute, 15 minute, one pot, one pan, budget, cheap, family dinner, weeknight
- homemade, from scratch, authentic, traditional, classic, best
